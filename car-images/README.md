# car-images/

PNG files in this folder are auto-loaded as manufacturer-badge replacements
on `drivers.html`, the inline Drivers Entered list on `signup.html`, and the
draw tool's reel, side panels, and grid-reveal cards.

For each car, save the image with the **exact filename** below. The page
gracefully falls back to the 3-letter brand badge for any car that doesn't
have an image yet, so you can drop these in incrementally.

## Image specs

- Format: **PNG** (transparent background recommended)
- Suggested dimensions: ~400×240 (any aspect ratio works — rendered with
  `object-fit: contain`)
- Suggested file size: under 100 KB each so the grid stays snappy
